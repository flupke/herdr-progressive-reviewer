This version requires Herdr 0.7.5 or later and jj 0.43.0 or later.

- Add persistent comment threads with MCP agent replies, recovered drafts,
  unread indicators, and shared active-agent selection. Threads retain their full

  visible unreviewed files, and `]r` or `[r` to move between guide comments.
